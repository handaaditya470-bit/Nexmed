# 🩺 NexMed - AI Health Report Analyzer

> An AI-powered healthcare platform that analyzes multiple medical reports, including ECGs, blood reports, chest X-rays, and ultrasound images, to assist in preliminary diagnosis and clinical decision-making.

## 📖 Overview

NexMed is a multi-modal AI healthcare project that leverages Deep Learning and Computer Vision to analyze different types of medical reports from a single platform.

The goal is to reduce the time required for preliminary report interpretation while providing an intuitive interface for healthcare professionals and patients.

**Supported Medical Reports**

* ❤️ ECG Analysis
* 🩸 Blood Report Analysis
* 🫁 Pneumonia Detection from Chest X-rays
* 🖥️ Ultrasound Image Analysis

---

## ✨ Features

### ❤️ ECG Analysis

* ECG image preprocessing
* AI-based cardiac disease classification
* Automatic prediction with confidence score

### 🩸 Blood Report Analysis

* Extracts blood parameters
* Detects abnormal values
* Generates easy-to-understand health summaries
* Highlights possible health concerns

### 🫁 Chest X-ray Analysis

* Detects pneumonia using Convolutional Neural Networks (CNNs)
* Displays prediction probability
* Supports medical image preprocessing

### 🖥️ Ultrasound Analysis

* AI-assisted ultrasound image interpretation
* Image preprocessing and classification
* Designed for future multi-organ support

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/NexMed.git
```

Move into the project

```bash
cd NexMed
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the server

```bash
python manage.py runserver
```

Open your browser

```text
http://127.0.0.1:8000
```
